# Changelog

## 1.0.0 — Preview

- Added bottom-tab navigation for Media, Reel snapshots, and Settings.
- Added native Media3 playback, downloads, playlists, search, background audio, fullscreen video, and picture-in-picture.
- Added explicit Instagram Reel capture with ordered offline snapshots and restart-safe downloads.
- Added native vertical Reel playback, adjacent preparation, watched-state resume, copy-link, speed, mute, and pause controls.
- Added per-snapshot quality/storage policies and comprehensive storage deletion controls.
- Removed Spotify, the legacy sidebar, and the abandoned Maps module.
- Hardened production networking and release signing; added a separate local preview variant.
